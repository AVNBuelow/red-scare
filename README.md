# Red Scare

This is Group AB's solution to the Red Scare assignment for the course Algorithm Design at the IT University of Copenhagen completed in Autumn 2026

## How to run

All scripts are in `programs/scripts` and will need Python3.

**Run all instances** — will run every problem on every instance in `programs/data` and writes to and generates `results.txt`:

```sh
python3 programs/scripts/run.py
```

In the table, `?` means the script timed out or failed, and `N/A` means the script doesn't exist yet.

It take a little while to generate the file, but you can follow along in the terminal.

**Run a single problem on a single instance** — the scripts read the instance from stdin and print the answer:

```sh
cd programs/scripts
python3 few.py < ../data/G-ex.txt
```

The scripts are `alternate.py` (A), `few.py` (F), `many.py` (M), `none.py` (N) and `some.py` (S).
